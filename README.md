## 🛠️ Herramientas usadas

> Esta sección ayudará a mostrar la progresión

- **Lenguaje:** Python
- **Librerías principales:** Python puro / NumPy / Seaborn, Matplotlib
- **Entorno:** Google Colab

## 🔍 Qué se hizo

1. Preparación de datos
2. Análisis exploratorio
3. Análisis de facturación
4. Ventas por categoría
5. Calificación promedio de la tienda
6. Productos más y menos vendidos
7. Envío promedio por tienda
8. Conclusiones para decidir que tienda se puede vender y así el dueño pueda invertir en un nuevo negocio.

## 🚀 Cómo ejecutarlo

Abrir el archivo `.ipynb` en Google Colab o Jupyter.
